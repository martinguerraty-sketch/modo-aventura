# Modo Aventura 📱

Aplicación web progresiva (PWA) móvil para organizar actividades diarias como misiones.

## Incluye
- Agenda diaria con fecha, hora, categoría y prioridad.
- Crear, completar y eliminar misiones.
- Puntos de experiencia, niveles y logros.
- Calendario mensual.
- Guardado local en el dispositivo y exportación JSON.
- Diseño adaptable y soporte básico sin conexión tras la primera carga.

## Publicar con Vercel
1. Entra a Vercel y elige **Add New → Project**.
2. Importa el repositorio `martinguerraty-sketch/modo-aventura`.
3. Elige **Other** como framework. Deja Build Command y Output Directory vacíos.
4. Pulsa **Deploy** y espera el enlace `*.vercel.app`.
5. Abre el enlace en el teléfono.

## Instalar
- **Android (Chrome):** menú ⋮ → “Instalar aplicación” o “Añadir a pantalla de inicio”.
- **iPhone (Safari):** Compartir → “Añadir a pantalla de inicio”.

Las misiones se guardan localmente en ese navegador; esta versión no tiene cuentas ni sincronización entre dispositivos, y no incluye notificaciones push.
